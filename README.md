# colpilot.colszunet

校园网监控插件用于查看校园网当前状态、监听运行情况和近期连通性记录。

## 功能

插件页面显示以下内容：

- 校园网目前状态
- 监听状态
- 24 小时和 7 天内的状态记录

插件后端会启动 worker 子目录中的 colszunet.py 监控程序，并读取该程序生成的 colszunet.log。后台监控程序由 Colpilot 的进程管理器登记；插件停用或 Colpilot 退出时会结束该程序。

## 配置

插件配置保存在 plugins\\colszunet\\config.ini 的 [colszunet] 配置节中，包含：

- 校园网账号和密码
- 检查间隔，默认值为 300 秒
- 登录、连通性检查和验证码相关配置

账号、密码、检查间隔和其他运行配置都会保存到该配置文件。密码输入框不会回显已经保存的密码；更新其他设置时，空密码会继续使用已经保存的密码，清除账号信息需要执行清除操作。配置文件包含校园网账号信息，请保护该文件。

账号和密码输入框会在停止输入约 700 毫秒后自动保存，连续输入期间只发送最后一次保存请求。保存设置后，监控程序会按照新的配置继续运行。

## 状态显示

24 小时和 7 天状态条按照时间段显示检测结果：成功显示绿色，失败显示红色，没有记录显示灰色。

## 服务接口

- GET /api/plugins/colszunet/status：读取当前状态、监听状态和 24 小时或 7 天历史状态段
- POST /api/plugins/colszunet/settings：保存账号、密码和检查间隔
